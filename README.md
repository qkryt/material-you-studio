# Material You Studio (M3 Expressive)

Интерактивный веб-сайт и генератор динамических цветовых схем в стиле **Google Material You (Material Design 3 Expressive)**.

🌐 **Открыть сайт:** [https://qkryt.github.io/material-you-studio/](https://qkryt.github.io/material-you-studio/)

## Возможности
- **Динамический движок цвета на базе OKLCH** — выбирай готовые пресеты обоев или любой произвольный цвет, и весь сайт пересчитает все токены Material Design 3 (`primary`, `secondary`, `tertiary`, `surface-container-*`, `outline` и т.д.).
- **5 алгоритмов палитры** — `Tonal Spot`, `Vibrant`, `Expressive`, `Neutral`, `Monochrome`.
- **Светлая / Тёмная тема и повышенный контраст** — мгновенное переключение с сохранением читаемости.
- **Интерактивный UI-кит M3** — кнопки, FAB, плитки быстрых настроек (Quick Settings), переключатели с иконками, слайдеры скругления и насыщенности, плеер с волнистым прогресс-баром (Squiggly Progress Bar), диалоги и snackbar.
- **Экспорт готовых CSS-переменных** — копирование всех `--md-sys-color-*` токенов текущей темы в один клик.

## Технологии
- Чистый HTML5 + CSS3 (CSS Custom Properties, OKLCH math, Material Symbols Rounded)
- Vanilla JavaScript без внешних зависимостей и сборщиков — мгновенная загрузка на GitHub Pages.
